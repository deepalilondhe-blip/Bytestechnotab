# Bytes Technolab - Page Documents

This folder contains all Google Doc / content files for each Bytes Technolab page.

## How to Add a New Page Doc
1. Save the Google Doc URL or .docx file here with the page name.
2. Update the .env file: set WORD_FILE_PATH to the new file path or URL.
3. Run: node cross_verify.js
